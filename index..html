Perguntas frequentes

Algumas informações sobre esta página e suas funções.

Este site é oficial de Game of Thrones?

Não. Este é um projeto de estudo com identidade visual própria, inspirado em fantasia medieval.

A página funciona no celular?

Sim. O layout foi criado para se adaptar a telas grandes e pequenas.

A pesquisa combina com os filtros?

Sim. Você pode pesquisar uma casa e escolher uma região ao mesmo tempo.

O formulário envia e-mails de verdade?

Ainda não. O formulário é uma demonstração local. Para enviar mensagens reais, será necessário conectar um serviço de formulários.

O tema escolhido fica salvo?

Sim. A escolha entre tema claro e escuro é salva no navegador deste dispositivo.
